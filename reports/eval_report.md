## Failures found during development and their fixes

Failures the evaluation and test suites surfaced while this version was built, and what changed:

| Found by | Failure | Cause | Fix |
|---|---|---|---|
| `quantagent eval --fixture` (direct) | 4 of 35 questions failed: Sharpe/Sortino expected `9.7e9`/`inf`, tool returned `null`; ranking order differed | The fixture's zero-volatility scheme has a zero denominator. The tools follow METHODOLOGY.md (ratio is null below 1e-9); the independent reference did not implement that rule | Reference now applies the documented rule and skips null metrics when ranking. Tools unchanged |
| Oracle-agent test (`tests/integration/test_eval_agent.py`) | Every question needed a repair round and the scripted run ran out of turns | The verifier counted 6-digit scheme codes in the answer as unlabelled numbers | Strings that appear in tool outputs or arguments (codes, dates) are no longer treated as numeric claims |
| Real-data ingest | 7 NAV rows rejected | mfapi.in returns `0.00000` NAVs on a few dates | Rejected with reason `nonpositive_value` (see `reports/rejected_rows.csv`); counted in `test_every_nav_row_accounted_for` |
| Real-data fetch | First full run spent minutes parsing dates | `pd.to_datetime` was called once per NAV string | Vectorised parsing in `sources.amfi.parse_mfapi` |
| Review of the worked example, after loading real Nifty TRI (data version 3) | `get_risk_metrics` gave Taurus Large Cap beta 0.951 and alpha 5.37% over 3y; `get_benchmark_comparison` gave 0.958 and 4.77% for the same fund and window | `get_risk_metrics` took daily returns of fund and index separately, then matched dates. Where one series skips a day, a two-day fund return was paired with a one-day index return. `get_benchmark_comparison` aligned prices first (correct). No test compared the two, and the evaluation had no beta question | `analytics.windows` now aligns prices before taking returns; `CALC_VERSION` 1.0.0 -> 1.1.0; metrics cache rebuilt. New real-data test checks alpha and beta from both tools against independent pandas (1e-9) for 5 schemes. New evaluation question `risk_beta`: with the old code the real-data run scores 35/36, with the fix 36/36 |
| Review of the worked example | Taurus Large Cap Direct showed a 2.51% expense ratio, high for a Direct plan; suspected Regular TER mapped to Direct | Checked against AMFI's October 2026 TER disclosure: Direct total TER 2.51% (1.88 base + 0.10 brokerage + 0.53 levies), Regular 2.73% | No bug. README notes the check; it is the highest of 35 large-cap Direct plans (median 1.08%) |
| Loading the 91-day T-bill series | First RBI DBIE export had cut-off price `99` and yield `06` | DBIE's TXT export rounds every column to integers | Exported as HTML instead (full precision); README says which export to use. 5 auction weeks with no published yield are rejected as `missing_or_unparseable` and forward-filled |
| Downloading Nifty TRI | The documented niftyindices endpoint returned an HTML page | The site moved the endpoint to `/BackPage/getTotalReturnIndexString` and limits each request to one year | Downloaded year by year in a browser session; the parser already accepted the resulting CSV |
