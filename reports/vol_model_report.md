# Volatility model: walk-forward results

Model version `vol21-har-20261021095439`; data_nature **real**, data version 3, data as of 2026-10-19. Generated by `quantagent train`.

Target: annualised realised volatility of the next 21 daily log NAV returns. Folds are calendar years; every model is refitted per fold on training rows whose target window ends at least 30 days before the fold starts (purge + embargo).

Protocol:

* **Selection period** (2014-01-01 to 2021-12-31, 18012 rows, 96 months): the served model is the one of HAR-RV, ridge and boosting with the lowest mean QLIKE here.
* **Test period** (2022-01-03 to 2026-09-17, 16637 rows, 57 months, from 2022-01-01): not used for any choice. All scores below are from this period.
* Regression models are fitted on log volatility and converted back with Duan's smearing factor (the mean of exp(residual) on the training rows), which corrects the downward bias of exp(E[log vol]).
* Training rows whose target window contains a suspect NAV (a daily move above 15%, or 5+ identical NAVs: the check_data_quality rules) are dropped. Those targets are in the past at fit time, so this uses no future information.

Lower is better. QLIKE is the Patton (2011) loss on variance; MAE is on annualised volatility. The DM columns test **HAR-RV (log, pooled OLS) (the served model) against the model in that row**: Diebold-Mariano on the monthly mean QLIKE differential, Newey-West lag 1, HLN correction. A negative statistic means the served model has the lower loss.

## Test period, filtered at the forecast origin

Drops 0 test rows whose scheme had a suspect NAV in the 252 trading days up to the origin. This is known when the forecast is made, so a live system could apply the same rule.

No test row is affected; the scores equal the headline.

## Diagnostic only: test rows with a clean target window

Drops 0 test rows whose *target* window contains a suspect NAV. That uses information from after the origin, so it is not a valid test result; it shows how much of the loss comes from a few NAV errors.

No test row is affected; the scores equal the headline.
